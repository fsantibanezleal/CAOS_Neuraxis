# Adversarial validation: base-0-08

For each requirement of [`requirements.md`](requirements.md), the check that tries to break it: what was planted or refuted, and the test that plants it. `scripts/check_sdd.py` fails when a requirement has no row here (or two), when a check is empty, and when a gate names a test that does not exist. A gate that is an existing test is named as it is; a gate under `tests/adversarial/` or `frontend/src/adversarial/` is a plant the suite that follows this document is to create, and the guard reports its row until it exists.

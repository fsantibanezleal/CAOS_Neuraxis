# Design

The engine owns the evaluation fixture, executable runner, frozen checkpoint selection and hash-audited summary. The product imports the separate evidence tree without recomputing model outcomes. The public Benchmark page loads the immutable adequacy report beside the original core results, and the semantic tab binds its 1,536-entry index to an audit SHA-256 before allowing a selected episode to load. Each episode is then checked against its indexed SHA-256 and identity. The index, report, lineage and trace files are packaged together only when both repository validators pass.

Tasks continues to provide useful deterministic file checks through the native broker. Its first-ready selection is stated at the point of use. Investigations remains an effect-free replay of the original core. The separate semantic lane is a measured research challenge, not a substitution for Tasks or a retuning of the corrected core.

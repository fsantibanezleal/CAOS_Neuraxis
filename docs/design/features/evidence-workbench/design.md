# evidence-workbench design

Offline export preserves measured bytes. Vite copies the derived artifact tree into static data. The viewer fetches the index, then a selected episode by reference; hash verification precedes normalization. Method comparison, calibration, confusion and timelines derive from canonical records. Simulation and imported traces remain labeled distinct lanes.

The product SDD defines the scope and deploy boundary. Requirements refer to executable gates and are not inferred from successful rendering or method names.

# Benchmark adequacy and what the app executes

The [audit JSON](../../data/derived/benchmark-adequacy.json) comes from the reflexmesh core index. The engine audit verifies every indexed episode SHA-256 before counting outcomes; the Neuraxis artifact check recomputes the index digest, all 12 success totals, seed-variable cells and perfect-method list. The app copies this report unchanged into its static evidence bundle and exposes it in **Benchmark → Outcomes → Adequacy**. It does not replace the [corrected results](corrected-results.md).

Seven methods, including M01's guarded state machine, solve all 1,200 core episodes each. Only 71 of 1,440 method/case/variant cells vary in binary success over ten seeds. M12 solves 1,160/1,200; all 40 failures are in C07 cancellation. The fitted allocation gate saw seven positive labels among 228 fit states and selected threshold 1.01, so it never chose to hand off through that gate. All four fixed-gate ablations matched M12 core success. Consequently the core matrix cannot demonstrate a learned task-success advantage, and repeated seeds do not provide ten independent task families.

The installed engine now checks preconditions before C07 cancellation and tests all six variants. That repair followed inspection of the held-out failures, so the historical result remains 1,160/1,200. A new semantic-transfer lane exercises opaque but type-compatible tool choices with real file outputs and independent truth. It is evaluated and reported separately; it does not reduce any existing matrix or turn a designed task suite into evidence of general software intelligence.

The completed semantic lane has 1,536 hash-checked episodes. M09 solves 38/128 and M12 18/128; M12 loses 22 paired cases to M09 and wins two. In an additional exploratory *offline* initial-arm study, the fitted router delegates on none of 32 held-out D07–D08 episodes and solves none, while always-M09 solves ten. The app shows the five observed selector outcomes with an explicit post-hoc oracle ceiling. `scripts/check_semantic_routing.py` binds those figures to the M04/M09 execution traces and the source index. This is not an online M12 comparison or evidence that learned metacontrol improves transfer.

The default **App → Tasks** tab uses `ReadyPolicy`: it chooses the first admissible dependency-ready action for source, data and release checks. It uses the reflexmesh native broker for admitted effects and verification, but does not run the learned routing gate or an LLM. **Investigations** replays measured controller traces without redispatching effects. The advanced local workspace supports reviewed deterministic workflows and explicit registered model methods. These interfaces have different authority and evidence; a Tasks outcome is not an M12 outcome.

# Workbench

Neuraxis offers a selected-case control instrument, an evidence viewer and an authenticated local execution client. These modes share episode records and visual readouts, while retaining their different authority and timing semantics.

- [Operating a scenario](01_operating-scenarios.md)
- [Evidence and native connection](02_evidence-and-native.md)
- [Verified user workflows](03_user-workflows.md)
- [Scientific theory and implementation](../theory/theory.md)

The six application routes are App, Introduction, Methodology, Implementation, Experiments and Benchmark. App concerns one selected case or one explicitly authored workspace recipe. Cross-case aggregates belong to Benchmark.
